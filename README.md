# Portafolio de escenografía

Abre `index.html` para ver el portafolio. Los archivos de la web son HTML, CSS y JavaScript estáticos.

## Editar el contenido

En `index.html`, cada proyecto es una sección con una galería y una ficha al pie. El menú enlaza al `id` de cada sección.

- Para añadir imágenes, guarda copias en `assets/` y duplica un enlace de la galería. Actualiza `href`, `src`, las dimensiones y la descripción `alt`.
- Para añadir un proyecto, duplica una sección y usa identificadores únicos para la sección y su ficha. Añade su enlace al menú.
- Dentro de `footer.ficha`, escribe los créditos confirmados debajo del nombre del proyecto. En publicidad puedes añadir `<p>Productora · Nombre</p>` y `<p>Dirección de arte · Nombre</p>`. Si el proyecto tiene una ficha verificada en IMDb, añade un enlace con el texto «IMDb».
- En el pie de la web, «Guardar como PDF» abre el diálogo de impresión con una composición para A4.

## GitHub Pages

Sube el contenido de esta carpeta a la raíz del repositorio. En **Settings → Pages**, selecciona **Deploy from a branch**, elige la rama que contiene `index.html`, selecciona **/ (root)** y guarda. Las rutas relativas funcionan también si la web queda bajo el nombre del repositorio.
